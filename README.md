# KnowledgeAI-RAG-Powered-Document-Assistant
KnowledgeAI is an AI-powered document assistant that uses LLMs and RAG to answer questions from PDFs and study materials. Built with React, FastAPI, Python, Ollama, Gemma, Sentence Transformers, and ChromaDB, it enables users to summarize documents, ask questions, and generate quizzes with context-aware answers and source references.
